# クライアント・アンケート管理のリリース記録

## 実装

- クライアント共通マスタに企業コードを追加。店舗管理から登録・編集・案件検索が可能。
- 業種テンプレートなしの店舗・施設登録を追加。A/B/C生成は明示的な別フォーム。
- 案件のクライアント選択、任意の店舗選択、用途、管理年、確定番号を保存。
- 選択店舗の所属クライアントをサーバーでも検証。番号がある案件にはクライアントを要求。
- 企業コード、管理年、確定番号、クライアント、用途で検索。番号はゼロ埋めを正規化した完全一致。
- 古い管理用名が厳密な命名形式に一致する場合は検索時だけ番号を読み取る。データの自動移行は行わない。
- 案件コピーは確定番号を引き継がない。DBでも企業内番号の重複を防止。
- 既存の店舗コードへA/B/C生成を再実行する際、他クライアント・異なるテンプレートへの合流を拒否。
- Claude Code用スキルをユーザーの `.claude/skills/aci-survey-builder/SKILL.md` に配置。Codex版も同内容。
