# 要件チェックリスト（Stage 1〜6 全項目）

凡例: 回答欄の「推奨のまま」= ユーザーが「推奨のまま進めて」と指示した項目。
優先度: MVP / P2 / 将来 / 不要 / 未定

## Stage 1：業務フロー

### 1-A. 段階報酬キャンペーン

| 項目 | 推奨 | 回答 | 優先度 |
|---|---|---|---|
| キャンペーン作成（管理） | 必要 | 推奨のまま | MVP |

| 参加登録（エントリー） | 後で | 推奨のまま | P2（自動参加。エントリー画面は摩擦） |
| 進捗の自動加算 | 必要 | 推奨のまま | MVP |
| ステージ達成→ボーナス付与 | 必要 | 推奨のまま | MVP |
| 達成演出 | 必要 | 推奨のまま | MVP（rank-celebration 流用） |
| 期間終了処理（未達者の扱い） | 必要 | 推奨のまま | MVP |
| 途中離脱者の復帰導線 | 後で | 推奨のまま | P2 |
